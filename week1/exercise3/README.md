# Ejercicio 3 — Run a model on your own machine

Este ejercicio se hizo desde la terminal, sin código propio.

- **Modelo:** `ministral-3:8b` (descarga de 6,0 GB)
- **Comando:** `ollama run ministral-3:8b`, en Ubuntu (WSL2)
- **Ejecución:** seis prompts en una sola sesión, sin cambiar parámetros

Los prompts usados, las valoraciones de cada respuesta y las conclusiones
están en el informe PDF entregado (W1-Ex1-4, sección Ejercicio 3).
